# 前端开发知识学习教程

## 一、前端开发概述

### 1.1 前端开发定义
前端开发（Front-end Development）是指构建用户界面（UI）和用户体验（UX）的过程，主要负责将后端数据和业务逻辑以可视化方式呈现给用户。

### 1.2 前端核心技术栈
- **HTML**：结构语言，负责页面内容和语义
- **CSS**：样式语言，负责页面外观和布局
- **JavaScript**：脚本语言，负责页面交互和动态效果

### 1.3 前端开发演变
- 静态页面时代（HTML+CSS）
- 动态交互时代（JavaScript+DOM操作）
- 工程化开发时代（框架+打包工具）
- 现代前端架构（SPA+组件化+服务端渲染）

## 二、HTML基础

### 2.1 HTML基本结构
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>页面标题</title>
</head>
<body>
    <!-- 页面内容 -->
</body>
</html>
```

### 2.2 常用HTML标签
- 语义化标签：`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`
- 文本标签：`<h1>-<h6>`, `<p>`, `<span>`, `<strong>`, `<em>`
- 列表标签：`<ul>`, `<ol>`, `<li>`, `<dl>`, `<dt>`, `<dd>`
- 表单标签：`<form>`, `<input>`, `<textarea>`, `<select>`, `<button>`
- 媒体标签：`<img>`, `<audio>`, `<video>`

### 2.3 HTML5新特性
- 语义化标签
- 本地存储：`localStorage`, `sessionStorage`
- 离线应用：`Application Cache`
- 音频/视频：`<audio>`, `<video>`
- 表单增强：新的input类型（email、url、number等）
- Canvas绘图和SVG矢量图形

## 四、JavaScript基础

### 4.1 JavaScript概述
JavaScript是一种脚本语言，用于为网页添加交互性和动态效果。

### 4.2 JavaScript基本语法
```javascript
// 变量声明
let variableName = value;
const constantName = value;
var oldVariable = value;

// 数据类型
let string = 'Hello World';
let number = 42;
let boolean = true;
let array = [1, 2, 3];
let object = { key: 'value' };
let nullValue = null;
let undefinedValue;

// 函数
function functionName(parameters) {
    // 函数体
    return value;
}

// 箭头函数（ES6+）
const arrowFunction = (parameters) => {
    // 函数体
};
```

### 4.3 JavaScript核心概念
- 作用域：全局作用域、函数作用域、块级作用域（ES6+）
- 变量提升（Hoisting）
- 闭包（Closure）
- 原型链（Prototype Chain）
- 事件循环（Event Loop）
- 异步编程：回调函数、Promise、async/await

### 4.4 DOM操作
```javascript
// 选择DOM元素
const element = document.querySelector('.className');
const elements = document.querySelectorAll('tagName');

// 修改元素内容
element.textContent = '新内容';
element.innerHTML = '<p>HTML内容</p>';

// 修改元素样式
element.style.color = 'red';
element.classList.add('newClass');
element.classList.remove('oldClass');

// 添加事件监听器
element.addEventListener('click', function() {
    // 事件处理逻辑
});
```

### 4.5 数组方法
```javascript
// 遍历数组
array.forEach(item => console.log(item));

// 数组映射
const newArray = array.map(item => item * 2);

// 数组过滤
const filteredArray = array.filter(item => item > 10);

// 数组归约
const sum = array.reduce((acc, curr) => acc + curr, 0);

// 数组查找
const foundItem = array.find(item => item === 'target');
```

## 五、TypeScript基础

### 5.1 TypeScript概述
TypeScript是Microsoft开发的JavaScript超集，添加了类型系统，提供更好的代码可读性、可维护性和工具支持。

### 5.2 安装和运行TypeScript
```bash
# 全局安装TypeScript
npm install -g typescript

# 创建TypeScript文件（.ts或.tsx）
echo 'console.log("Hello TypeScript")' > hello.ts

# 编译TypeScript
tsc hello.ts

# 运行编译后的JavaScript文件
node hello.js
```

### 5.3 TypeScript基础类型
```typescript
// 布尔值
let isDone: boolean = false;

// 数字（支持二进制、八进制、十进制、十六进制）
let decimal: number = 6;
let hex: number = 0xf00d;
let binary: number = 0b1010;
let octal: number = 0o744;

// 字符串（支持模板字符串）
let color: string = "blue";
let fullName: string = `Bob Bobbington`;
let age: number = 37;
let sentence: string = `Hello, my name is ${ fullName }.

I'll be ${ age + 1 } years old next month.`;

// 数组（两种写法）
let list1: number[] = [1, 2, 3];
let list2: Array<number> = [1, 2, 3];

// 元组：已知长度和类型的数组
let x: [string, number];
x = ["hello", 10]; // OK
// x = [10, "hello"]; // Error

// 枚举：为数值集合提供更友好的名字
enum Color {
    Red,
    Green,
    Blue,
}
let c: Color = Color.Green; // 1

// 任意类型：可以赋予任意类型的值
let notSure: any = 4;
notSure = "maybe a string instead";
notSure = false; // 也可以是boolean

// 空值：表示没有任何类型
function warnUser(): void {
    console.log("This is my warning message");
}

// Null和Undefined
let u: undefined = undefined;
let n: null = null;

// Never类型：表示永不存在的值的类型
function error(message: string): never {
    throw new Error(message);
}

// Object类型：表示非原始类型
declare function create(o: object | null): void;
```

### 5.4 接口（Interfaces）
```typescript
// 基本接口
interface Person {
    firstName: string;
    lastName: string;
    age?: number; // 可选属性
    readonly id: number; // 只读属性
}

let user: Person = {
    id: 123,
    firstName: "John",
    lastName: "Doe",
};

// 接口用于函数类型
interface SearchFunc {
    (source: string, subString: string): boolean;
}

let mySearch: SearchFunc = function (src, sub) {
    return src.search(sub) !== -1;
};

// 接口用于数组类型
interface StringArray {
    [index: number]: string;
}

let myArray: StringArray = ["Bob", "Fred"];
```

### 5.5 类（Classes）
```typescript
class Greeter {
    greeting: string;
    static readonly MAX_COUNT: number = 10; // 静态属性

    // 构造函数
    constructor(message: string) {
        this.greeting = message;
    }

    // 方法
    greet() {
        return `Hello, ${this.greeting}!`;
    }
}

let greeter = new Greeter("world");
console.log(greeter.greet()); // 输出：Hello, world!

// 继承
class Animal {
    move(distanceInMeters: number = 0) {
        console.log(`Animal moved ${distanceInMeters}m.`);
    }
}

class Dog extends Animal {
    bark() {
        console.log("Woof! Woof!");
    }
}

const dog = new Dog();
dog.bark(); // 输出：Woof! Woof!
dog.move(10); // 输出：Animal moved 10m.

// 访问修饰符：public、private、protected
class Employee {
    public name: string;
    private salary: number;
    protected department: string;

    constructor(name: string, salary: number, department: string) {
        this.name = name;
        this.salary = salary;
        this.department = department;
    }

    getSalary() {
        return this.salary;
    }
}
```

### 5.6 函数（Functions）
```typescript
// 函数类型
function add(x: number, y: number): number {
    return x + y;
}

let myAdd: (x: number, y: number) => number = add;

// 可选参数和默认参数
function buildName(firstName: string, lastName?: string): string {
    if (lastName) {
        return `${firstName} ${lastName}`;
    } else {
        return firstName;
    }
}

// 默认参数
function buildName2(firstName: string, lastName: string = "Smith"): string {
    return `${firstName} ${lastName}`;
}

// 剩余参数
function buildName3(firstName: string, ...restOfName: string[]): string {
    return `${firstName} ${restOfName.join(" ")}`;
}

// 函数重载
function reverse(x: number): number;
function reverse(x: string): string;
function reverse(x: number | string): number | string {
    if (typeof x === "number") {
        return Number(x.toString().split("").reverse().join(""));
    } else {
        return x.split("").reverse().join("");
    }
}
```

### 5.7 泛型（Generics）
```typescript
// 泛型函数
function identity<T>(arg: T): T {
    return arg;
}

let output1 = identity<string>("myString");
let output2 = identity<number>(100);
let output3 = identity(100); // 类型推断

// 泛型接口
interface GenericIdentityFn<T> {
    (arg: T): T;
}

// 泛型类
class GenericNumber<T> {
    zeroValue: T;
    add: (x: T, y: T) => T;
}

let myGenericNumber = new GenericNumber<number>();
myGenericNumber.zeroValue = 0;
myGenericNumber.add = function (x, y) {
    return x + y;
};

// 泛型约束
interface Lengthwise {
    length: number;
}

function loggingIdentity<T extends Lengthwise>(arg: T): T {
    console.log(arg.length);
    return arg;
}
```

### 5.8 高级类型
```typescript
// 联合类型（Union Types）
let value: string | number;
value = "hello"; // OK
value = 42; // OK

// 类型别名
type Point = { x: number; y: number };
type stringOrNumber = string | number;

// 交叉类型（Intersection Types）
type A = { a: number };
type B = { b: string };
type C = A & B; // { a: number; b: string }

// 类型守卫
function isFish(pet: Fish | Bird): pet is Fish {
    return (pet as Fish).swim !== undefined;
}

// 类型断言
let someValue: any = "this is a string";
let strLength: number = (someValue as string).length;
```

## 六、前端框架

### 6.1 React
Facebook开发的JavaScript库，用于构建用户界面。
```javascript
import React from 'react';

function Component() {
    const [state, setState] = React.useState(initialValue);

    return (
        <div>
            <h1>Hello React</h1>
            <p>{state}</p>
            <button onClick={() => setState(newValue)}>
                更新状态
            </button>
        </div>
    );
}

export default Component;
```

### 6.2 Vue
渐进式JavaScript框架，由尤雨溪开发。
```vue
<template>
    <div>
        <h1>Hello Vue</h1>
        <p>{{ message }}</p>
        <button @click="updateMessage">
            更新消息
        </button>
    </div>
</template>

<script>
export default {
    data() {
        return {
            message: '欢迎使用Vue'
        };
    },
    methods: {
        updateMessage() {
            this.message = '新的消息内容';
        }
    }
};
</script>
```

### 6.3 Angular
Google开发的前端框架，基于TypeScript。
```typescript
import { Component } from '@angular/core';

@Component({
    selector: 'app-root',
    template: `
        <div>
            <h1>Hello Angular</h1>
            <p>{{ message }}</p>
            <button (click)="updateMessage()">
                更新消息
            </button>
        </div>
    `
})
export class AppComponent {
    message: string = '欢迎使用Angular';

    updateMessage() {
        this.message = '新的消息内容';
    }
}
```

## 八、现代前端架构

### 8.1 单页面应用（SPA）
- 优点：用户体验好，加载速度快
- 缺点：SEO优化困难，首屏加载慢
- 解决方案：服务端渲染（SSR）、静态网站生成（SSG）

### 8.2 组件化开发
- 将页面拆分为可复用的组件
- 每个组件负责特定功能
- 提高代码复用性和维护性

### 8.3 状态管理
- 组件状态（Component State）
- 全局状态管理：Redux（React）、Vuex（Vue）、Pinia（Vue3）
- 状态管理库：Zustand、Jotai

## 九、前端安全

### 9.1 XSS攻击
- 定义：跨站脚本攻击
- 预防：
  - 输入验证
  - 输出编码
  - CSP（内容安全策略）
  - 避免使用innerHTML

### 9.2 CSRF攻击
- 定义：跨站请求伪造
- 预防：
  - 使用CSRF令牌
  - 验证HTTP Referer
  - 同源检测

### 9.3 点击劫持
- 定义：通过透明层覆盖在正常页面上，诱使用户点击
- 预防：
  - X-Frame-Options头
  - CSP（内容安全策略）
  - JavaScript防止iframe嵌套
